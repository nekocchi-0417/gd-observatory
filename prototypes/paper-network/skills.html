How to read this map

Concept links come from whole-phrase matches in titles and draft catalog metadata, not full-text analysis. Edit the matching phrases to test a different lens. Shared concepts do not imply agreement, citation links or causal effects.

“GD areas” shows existing topic assignments and explicit related-area tags from the October 22 reviews, within this Skills collection. The source list is exploratory, not a systematic review. Citation counts measure recorded attention, not quality; a missing count is not zero. Coverage and continuity require source review.
