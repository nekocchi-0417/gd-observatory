How the evidence was selected

Scope. This library draws on the skills and judgement areas of the 11 October 2026 landscape review. It includes experiments, surveys, reviews and earlier work on automation that helps define the questions.

Selected studies. We prioritise direct relevance, objective outcomes and explicit comparison groups. The classroom and coding experiments test unaided learning; the meta-analysis compares human-only, AI-only and combined performance. Supporting studies add different findings and methods. This shortlist is AI-assisted; no completed human review is recorded for this prototype.

Evidence map. Themes group the scan's existing construct tags. A reference can belong to several themes; counts describe this collection and do not rate evidence quality. The map and library use the same classification rules.

Time matters separately. A study can run for months while only testing each skill once. Study duration, delayed follow-up and repeated tests of the same people need separate checks. Longer studies are useful only where their outcomes fit the question.

Limits. This is an editorial selection from a broad AI-assisted scan, not a systematic review or a formal quality ranking. The scan reached search limits. Imported records are reading leads; their inclusion does not establish a finding or a field-wide gap.
